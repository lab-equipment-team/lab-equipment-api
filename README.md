# lab-equipment-api

## Project Description
A Rails API for managing lab equipment, categories, and maintenance records.

## Setup Instructions
git clone https://github.com/lab-equipment-team/lab-equipment-api.git
cd lab-equipment-api
bundle install
bin/rails db:create db:migrate db:seed
bin/rails server
